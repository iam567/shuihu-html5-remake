# 素材工坊

游戏用到的全部新美术，都从这里生产和审核。网页版工坊：https://game.areu.pro/shz/ （有登录保护）。

## 内容

- `dist/`：工坊网页，以及从 ROM 提取的原版素材目录，包括 116 张完整地图、31 组图块资源、60 组人物精灵、40 张头像、8 套字库和界面图块。可以按分类或编号搜索，点开能看到原图、尺寸、调色板，以及关联的地图和图块。
- `production/`：每一批生图任务的任务表（`jobs.json`）、提示词和参考图清单，包括整张地图、人物行走图、界面按钮、战斗特效、片头和结局、地图摆设、音乐等。生成的原始图片体积太大，不进仓库，保存在生图服务器和 CMS 备份里。
- `tools/`：准备任务、对齐、切图、拼图、审核和导出到游戏的脚本。每个脚本开头都写了用途和用法。
- [ART-PRODUCTION.md](ART-PRODUCTION.md)：最初制定的生产规则，包括图块必须和原版逐格对应、跨格物件整组审核、招牌文字不能让 AI 猜。

## 流程

1. 用 `prepare_*.py` 生成任务表：参考图取自原版，提示词写明哪些东西必须保留，避免 AI 画成别的东西。
2. 在生图服务器上用 `run_batch.py` 提交，最多 10 个并发。被服务拒绝的任务不绕过、不重复提交。
3. 结果和原版并排对照审核。地图要叠加原版网格、出入口和调查点核对，人物要对照原版的动作和比例。
4. 用 `export_*.py` / `finalize_*.py` 导出到 `../shuihu-html5/dist/assets/`。

画风分三种：原版素材、吉卜力手绘（`ghibli`）、HD-2D 光影（`hd2d`）。新素材的坐标都是原版的 4 倍，人物位置、碰撞、门口和剧情触发全部沿用原版数据，不按新图推断。

API 密钥和服务器凭据都不在仓库里。
