# 隐藏道具、银两与一次性领取核对

已确认原版隐藏调查奖励 **39 处：35 处物品、4 处银两，共 4200 两**。并非每间房屋都有隐藏物品。坐标以地图左上角为 (0,0)，单位为 32 像素格。

原 ROM 的 DC84A 按章节指向 8 字节地点记录；1A65C 用地图号与正前方格索引 FF6028 匹配地点，设置 FFE500 + 章节×4 的位；1A5F6 在领取后及重新加载地图时把该格改为 50，保留阻挡并禁止再次调查。全部 39 条脚本均是 `0016 奖励 FFFF`，没有额外分支；一次性限制存在于脚本外部，不能只移植奖励指令。

本次修正新增独立 pickupFlags，首次领取后立即置位、格子改 50，重新进图/读档恢复。重复调用同一隐藏事件也不会重复奖励。普通剧情 flag 与隐藏领取 flag 分开存储。

## 其他调查点与剧情奖励

0400 的 (9,12) / 事件80和0800的(18,5) / 事件80不在隐藏领取表中；两者原脚本分别是对白99和285，不能标成隐藏物品。

额外奖励入口中，320 个只是指向同一隐藏奖励脚本的表项别名，不是新增320件道具。唯一另一个奖励流程是第10组事件48（0xEA618），发放物品75、89、84，属于剧情奖励，不套用隐藏地点领取位。

## 验证与缺口

`node tools/test_hidden_items.mjs` 对全部39处逐一验证了奖励值、领取位、再次调查不重复、存档恢复后不重复和碰撞50恢复，以及39处均有至少一格可通行的邻接调查位置。开场回归测试仍通过。

触摸交互已有0x80–0xAF邻接调查入口；39处均为90–93，因此都能经相同入口调查。尚未逐处通过浏览器角色走到目标实际点击；地图坐标与脚本关联来自原表及原碰撞层逐项比对。已有旧存档没有pickupFlags时按未领取处理，因为旧版没有保存这项状态，无法可靠反推是否曾领取。
