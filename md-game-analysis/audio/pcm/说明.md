# 原生 PCM 样本与播放机制

已从基准 ROM 解析 Z80 样本表，并用原游戏 Z80 驱动实测验证。导出 **126 个可选择的 ROM 样本描述符、56 个不同 ROM 数据区间、250 个播放速率版本 WAV**。不同描述符经常共享同一段波形，只调整延时产生不同音高；250 个 WAV 不是 250 种独立素材。

## 文件

- `pcm-index.json`：完整描述符、ROM 位置、长度、延时、原始文件哈希、关联音效 ID、测得时钟间隔和 WAV 文件。
- `raw/*.u8`：56 个去重的原始区间，8-bit unsigned 单声道 PCM，中心为 128，共 224,116 字节。区间之间仍可能部分重叠。
- `wav_priority/` 与 `wav_normal/`：原驱动两种命令优先级分支各 125 个 WAV，均为不衰减波形。WAV 的整数采样率取实际测得播放频率的最近整数，索引保留精确分数。
- `measured-timing*.json`：每个描述符首帧的 DAC 写入间隔直方图、前 64 个输出值（短样本取实际长度）、Z80 初始化字段。
- `z80-driver.bin` 与 `z80-disassembly.txt`：驱动与辅助反汇编。0x1AD 之后是描述符数据，线性列表把数据也解成了指令，不能当作全部代码阅读。
- `extract_pcm.py`、`measure_pcm.py`：可复现提取与测量脚本。

## 结构与证据

ROM `0x1E3B02` 是复制到 Z80 RAM 的驱动；Z80 `0x1AD` / ROM `0x1E3CAF` 是 8 字节描述符表。字段依次是小端源地址、小端字节长度、2 字节串行 bank 参数、延时、下一命令号。命令按低 7 位选样本，1 为 Z80 RAM 0x0010 的单字节特殊项，2..127 是本轮导出的 ROM 样本项。命令 0 的语义不能等同于一条普通样本描述符。

Z80 0x0162..016B 从描述符读源地址和长度；0x016E..0182 等待 delay 次循环，读取一字节，减去 0x80，可选算术右移衰减，再加回 0x80 后写到 YM2612 DAC。音量等级通过 0x0178..017F 的自修改补丁把 NOP 替换成 SRA A：等级 0 不衰减，1..4 对应 1..4 位算术右移。原始 PCM 保留未衰减数据。

初始 ROM 内 0x30 附近的值会被启动逻辑修改；现成模拟器运行态 `runtime/audio-test/music0/zram.bin` 确认 0x30..35 为 `00 60 00 CB 2F 3E`，bank 高字节偏移为 0，衰减补丁是 CB 2F（SRA A）。因此样本映射为 `bank_high*65536 + (bank_low&1)*32768 + (z80_source&32767)`。

在独立模拟器实例中冻结 68000 主程序，对每个描述符分别触发普通/优先命令，并截获原游戏 Z80 驱动对 DAC 的真实写入。126 个描述符、两种模式的可观察前缀都与 ROM 提取字节逐字节一致。多字节样本均测得一致间隔：

- 优先命令：`(237 + 14*delay) * 15` 主时钟周期。
- 普通命令：`(217 + 14*delay) * 15` 主时钟周期。

NTSC 标称主时钟采用模拟器源码 `core/system.c` 所列 53,693,175 Hz。例 delay=1 时，优先模式约 14,261 Hz，普通模式约 15,496 Hz；delay=43 的优先模式约 4,266 Hz。这是**驱动播放速率**，原素材录制时采样率未知。真实整机总线争用、PAL 模式、音乐与音效打断会改变时序，不能将受控测试值宣称为所有运行场景的固定值。

ID 84 是单字节 ROM 样本，没有第二次写入可测间隔；仅导出 raw，不为它猜测 WAV 采样率。ID 1 是特殊 RAM 样本，没有作为 ROM 素材提取。

范围包括完整低 7 位可选描述符，不代表每项都会被正常剧情调用；音效分流表的直接引用已在索引中列出，音乐脚本动态引用仍需后续追踪。没有给样本主观命名为角色台词或具体乐器。
